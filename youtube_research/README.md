# 動画リサーチ

YouTube ショート動画を、キーワードと期間で検索し、再生倍率(再生回数 ÷ チャンネル登録者数)で並べ替えるツールです。ビルド不要の静的な Web アプリで、YouTube Data API v3 を使います。

## 使い方

```
cd youtube_research
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開き、YouTube Data API のキーとキーワードを入力して「最新データを取得」を押します。`file://` で直接開くとモジュールが動かないため、上のようにサーバー経由で開いてください。

- API キーと設定は、このブラウザの localStorage にだけ保存されます。
- 1回の取得は、検索1ページ(50件)につき約100ユニットを消費します。200本で最大約1,000ユニット、1日の枠は1万ユニットです。
- 「ショート」は動画の長さで判定します(60秒以内、または3分以内を選択)。
- 一覧のチャンネル名を押すと、チャンネル詳細が開きます。登録者数、直近の投稿本数、平均再生、再生倍率、投稿頻度、投稿日別の再生数のグラフ、再生数の多い動画を表示します。詳細の取得は、1回あたり約3〜10ユニットです。日ごとの再生数の推移は本人以外は取得できないため、グラフは「その日に投稿された動画の現在の再生数の合計」です。
