# 麻雀打牌アドバイザー（PC常駐・手動入力＋実験的画面認識）

オンライン雀卓でのプレイ中に、自分の手番で「切るならこれ」を即座に提示する
ローカル常駐ツールです。**牌を切る操作は必ず自分で行います。自動プレイ（オー
トプレイ）機能は一切ありません。**

## スコープ・使い方についての重要な注意

- **想定用途は「AI対戦・フリー対局」限定です。** 段位戦・レート戦・課金が絡む
  対局や、他の実在プレイヤーとの真剣勝負での使用は、多くのオンライン雀卓の利用
  規約で外部ツール利用として禁止されている場合があります。使用前に、ご利用中の
  サービスの利用規約を確認し、規約に反しない範囲でお使いください。
- 本ツールは**効率（何切る）に特化したアシスタント**です。何巡目か、相手の捨て
  牌からの危険牌読み、点数状況を踏まえた押し引き判断などの高度な戦略は行いませ
  ん。あくまで「シャンテン数と受け入れ枚数を最大化する」という一般的な効率セオ
  リーに基づく提案です。
- 画面を自動で読み取る「vision」モードは実験的機能です。オンライン雀卓ごとに
  牌のデザイン・レイアウトが異なるため、**ご利用の雀卓に合わせた個別キャリブ
  レーションが必須**であり、動作を事前に保証できません。まずは手入力モード
  （下記）から使い始めることを強く推奨します。

## セットアップ

```
pip install -r requirements.txt
```

Python 3.10 以降を推奨します。`overlay` モードを使うには Tk（Windows/Mac の
公式インストーラには標準搭載）が必要です。

## 使い方

### 1. 手入力モード（`cli`） — 追加設定なしで今すぐ使えます

```
python main.py
```

自分の手牌を **mpsz記法** で入力して Enter を押すだけです。

```
> 123456789m123p1s9s
→ 切るなら: 1s  （テンパイ化！待ち: 9s）
```

- `m`=萬子, `p`=筒子, `s`=索子, `z`=字牌（1z東 2z南 3z西 4z北 5z白 6z発 7z中）
- 13枚（まだ自分の番でない時の状況確認）・14枚（ツモ後、切る牌を決める時）の
  どちらも入力できます。
- `v <tiles>` で「見えている牌」（他家の捨て牌・ドラ表示牌・自分の捨て牌な
  ど）を追加登録できます。残り枚数の精度が上がり、"すでに残り0枚の待ち" を
  避けるといった判断ができるようになります。新しい局が始まったら `reset`。
- `help` で使い方を再表示。

牌を数える→打つまでの判断が10秒以内という前提なら、13〜14文字の入力＋Enter
は十分速く、計算自体は即時です。

### 2. オーバーレイモード（`overlay`） — 常駐して手早く入力

```
python main.py overlay
```

常に最前面に小さな入力ウィンドウが出ます。グローバルホットキー
`Ctrl+Alt+H` を押すと、ゲーム画面にフォーカスがあってもこの入力欄に一発で
フォーカスが移るので、Alt+Tab せずに手牌を打ち込めます。`Ctrl+Alt+R` で
「見えている牌」の記録をリセットします。

### 3. 画面認識モード（`calibrate` / `vision`） — 実験的機能

手入力すら省きたい場合向けの、画面から手牌を自動で読み取る機能です。**事前に
必ずキャリブレーションが必要**です。

```
python main.py calibrate
```

1. 画面上で自分の手牌が並んでいる範囲をドラッグして選択します。
2. その範囲に何枚の牌があるか入力します（ツモ後なら14、それ以外は13）。
3. Enter を押すごとにその範囲を撮影し、各牌の切り出し画像を1枚ずつ確認しな
   がらラベル（`5m`, `1z` など）を入力して登録します。実際の対局中に何度か
   行い、出現した牌をその都度登録していくことで `templates/` フォルダに牌画
   像セットができていきます。

ある程度登録できたら:

```
python main.py vision          # 今の画面を1回読み取って解析
python main.py vision --watch  # Ctrl+Alt+M を押すたびに読み取って解析
```

認識できなかった牌がある場合はエラーで知らせます（誤った牌で判断させるより
安全側に倒しています）。その場合は `calibrate` でテンプレートを追加するか、
手入力モードで代わりに入力してください。

**制限事項:** 牌のスキン変更・UIレイアウト変更・解像度変更があるたびに再キャ
リブレーションが必要になる可能性があります。赤ドラの見た目の違いは現時点で
は区別しません（シャンテン計算には影響しません）。

## テスト

```
pytest
```

エンジン（シャンテン・受け入れ計算）と画面認識ロジックのユニットテストが
含まれています。

## 仕組み（内部構成）

- `mahjong_advisor/engine/` — シャンテン計算は実績のある
  [`mahjong`](https://pypi.org/project/mahjong/) パッケージを利用。各打牌候補
  ごとに「切った後のシャンテン数」「受け入れ牌の種類・残り枚数」を計算してラン
  キングします（`ukeire_live` = 見えている牌を考慮した残り生牌数）。
- `mahjong_advisor/cli.py` / `mahjong_advisor/ui/overlay.py` — 上記エンジンを
  呼び出すだけの薄い入出力層。
- `mahjong_advisor/vision/` — `mss` で画面キャプチャ、OpenCV のテンプレートマ
  ッチングで牌を認識し、結果をそのままエンジンに渡します。
