# card_stat_stamp — 鑑定カード写真にグレード・POP・日付を焼き込む

PSAスラブの写真に、**グレード（PSA10）／鑑定枚数（POP 176）／読み取り日付**
を、白抜き＋赤フチの太字で焼き込みます。

```
pip install Pillow numpy
python -m card_stat_stamp slab.jpg --grade 10 --pop 176
```

出力は既定で `slab_stamped.jpg`。日付は未指定なら**実行日**が入ります。

```
PSA10 / POP 176 / 2026/09/20 時点 -> slab_stamped.jpg
```

## 数値の取得元

| 入れる値 | どこから読むか |
| --- | --- |
| グレード | **スラブのラベル右上**の数字（`GEM MT` や `NM-MT` の右の `10` / `8` など） |
| POP | **鑑定分布データ画面**の、そのグレードのチップに出ている枚数 |
| 日付 | 実行日（`--date` で上書き可） |

数値の読み取り自体はこのツールでは行いません（OCRは使っていません）。写真と
スクショから読んだ値を引数で渡してください。

## 主なオプション

| オプション | 説明 |
| --- | --- |
| `--grade` | ラベルのグレード。`10` / `PSA10` / `PSA 10` いずれでも可 |
| `--pop` | そのグレードの枚数。`176` / `1,234` など文字列でも可 |
| `--date` | 日付。`YYYY-MM-DD` / `YYYY/MM/DD`（既定: 実行日） |
| `--no-date` | 日付行を入れない |
| `-o, --output` | 出力先（既定: `<入力名>_stamped.jpg`） |
| `--fill` / `--outline` | 文字色・フチ色（既定: 白／赤 `#E41E26`） |
| `--font` | 使うフォントのパス |
| `--block-top` | グレード行の上端。画像高さに対する比（既定: 0.600） |
| `--date-top` | 日付行の上端。同じく比（既定: 0.880） |
| `--quality` | JPEG の品質（既定: 95） |

## 配置について

`card_title_overlay` と違い、このツールは**あえてカードの上に重ねます**（数字を
見せるのが目的のため）。スラブ写真は構図がほぼ一定なので、位置と文字サイズは
画像サイズに対する比率で決めています。

| 行 | 文字の高さ（画像高さ比） | 上端 | 横位置 |
| --- | --- | --- | --- |
| `PSA10` | 0.0585 | 0.600 | 中央 |
| `POP 176` | 0.0715 | グレード行の下 0.008 | 中央 |
| `2026/09/20 時点` | 0.041 | 0.880 | 右端から 0.107 |

構図が違う写真では `--block-top` / `--date-top` で上下にずらせます。

## 文字について

描画は `card_lettering`（`card_title_overlay` と共通）を使っています。この3行は
英数字が中心で、漢字ほど画数が詰まらないため、太らせ量だけ本文より強め
（0.055）にしてあります。
