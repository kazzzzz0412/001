# card_grade_marker — 鑑定分布データの1グレードだけを強調する

PSA鑑定分布データ（グレード別の枚数チップが横一列に並ぶ画面）のスクリーン
ショットから、**該当グレード以外のチップを背景色で塗りつぶし、残した1つに大
きな矢印を付ける**ツールです。

例えば PSA 8 / 6 / 4 / 3 / 2 のチップが並んだ画面から PSA 6 を指定すると、
PSA 6 のチップだけが残り、その横に大きな矢印が描かれた画像が出力されます。

## 使い方

```
pip install Pillow numpy
python -m card_grade_marker screenshot.jpg
```

出力は既定で `screenshot_marked.png`。`-o` で変更できます。

対象チップは既定で **アプリ側で選択中のチップ（白枠のもの）** を自動判別しま
す。別のグレードを残したいときは、左から数えた位置を指定します。

```
python -m card_grade_marker screenshot.jpg --target 3 -o psa4.png
```

どのチップがどの位置かは `--list` で確認できます。

```
$ python -m card_grade_marker screenshot.jpg --list
chip row: rows 1654-1875, background rgb(15, 15, 15)
  1: x 31-270 (width 240)
  2: x 301-540 (width 240) <- selected
  3: x 571-810 (width 240)
  4: x 841-1080 (width 240)
  5: x 1111-1289 (width 179)
```

### 主なオプション

| オプション | 説明 |
| --- | --- |
| `-t, --target` | `auto`（選択中のチップ）または左から数えた位置（1始まり） |
| `-o, --output` | 出力先（既定: `<入力名>_marked.png`） |
| `--side` | 矢印を置く側。`auto` / `left` / `right`（既定は広い方） |
| `--color` | 矢印の色。色名または `#RRGGBB`（既定: アンバー `#FFC23C`） |
| `--fill` | 消した部分の色。`bg`（ページ背景を自動採取）または任意の色 |
| `--pad` | チップ行の上下を追加で消す行数 |
| `--ring` | 残したチップの周囲にも枠を描く |
| `--band Y0:Y1` | チップ行の自動検出を使わず、行範囲を直接指定する |
| `--list` | 検出結果だけを表示して終了 |

## 検出のしくみ

OCR は使わず、形で見つけます。

1. 画面全体から、**同じ幅・同じ中心を持つ水平な線の対**（＝角丸長方形の上辺と
   下辺）を探し、チップ行の候補とする。
2. 候補の帯の中で、背景より明るい画素を x 方向に射影し、連続した列をチップ候補
   とする。**上辺と下辺の両方が閉じている**ものだけをチップとして残す（見出し
   の文字列はこの条件で落ちる）。
3. 幅とピッチが揃っている候補ほど高く採点し、最も「チップ行らしい」帯を採用する。
4. 各チップの**枠線**が白ければ、アプリ側で選択中のチップと判定する（チップ内
   の数字も白いため、枠だけを見る）。

そのため、白枠の選択チップが写っていないスクリーンショットでは自動判別ができ
ません。その場合は `--target` で位置を指定してください。行の検出自体に失敗する
ときは `--band` で行範囲を渡せます。
