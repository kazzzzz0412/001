# card_grade_marker — 鑑定分布データの1グレードだけを強調する

PSA鑑定分布データのスクリーンショットから、**該当グレード以外を消して、残した
1つを目立たせる**ツールです。アプリの画面は2種類あり、どちらにも対応します。

| レイアウト | 見た目 | 指定方法 |
| --- | --- | --- |
| チップ | グレード別の枚数チップが横一列 | 自動（白枠の選択中チップ）／`--target` |
| 表 | グレード / 枚数 / クオリファイヤ の表 | `--row N`（上から数えた行） |

例えば PSA 8 / 6 / 4 / 3 / 2 のチップが並んだ画面から PSA 6 を指定すると、
PSA 6 のチップだけが残り、その横に大きな矢印が描かれた画像が出力されます。

## 使い方

```
pip install Pillow numpy
python -m card_grade_marker screenshot.jpg
```

出力は既定で `screenshot_marked.png`。`-o` で変更できます。

対象チップは既定で **アプリ側で選択中のチップ（白枠のもの）** を自動判別しま
す。別のグレードを残したいときは、左から数えた位置を指定します。

```
python -m card_grade_marker screenshot.jpg --target 3 -o psa4.png
```

どのチップがどの位置かは `--list` で確認できます。

```
$ python -m card_grade_marker screenshot.jpg --list
chip row: rows 1654-1875, background rgb(15, 15, 15)
  1: x 31-270 (width 240)
  2: x 301-540 (width 240) <- selected
  3: x 571-810 (width 240)
  4: x 841-1080 (width 240)
  5: x 1111-1289 (width 179)
```

### 主なオプション

| オプション | 説明 |
| --- | --- |
| `-t, --target` | `auto`（選択中のチップ）または左から数えた位置（1始まり） |
| `-o, --output` | 出力先（既定: `<入力名>_marked.png`） |
| `--side` | 矢印を置く側。`auto` / `left` / `right`（既定は広い方） |
| `--color` | 矢印の色。色名または `#RRGGBB`（既定: アンバー `#FFC23C`） |
| `--fill` | 消した部分の色。`bg`（ページ背景を自動採取）または任意の色 |
| `--chip X0:X1` | チップの自動検出を使わず、残す列範囲を直接指定する |
| `--pad` | チップ行の上下を追加で消す行数。`N` または `上:下` |
| `--ring` | 残したチップの周囲にも枠を描く |
| `--band Y0:Y1` | チップ行の自動検出を使わず、行範囲を直接指定する |
| `-r, --row N` | 表レイアウトで残す行（上から1始まり、ヘッダーと合計を除く） |
| `--mark` | 表で残した行の印。`ring`（既定）/ `arrow` |
| `--list` | 検出結果だけを表示して終了 |

## 表レイアウト（現行のアプリ）

表には「どれが自分のカードか」を示す印が無いので、**行番号で指定**します。

```
$ python -m card_grade_marker table.jpg --list
table: x 48-1241, background rgb(15, 15, 15)
  header: rows 425-551
  grade row 1: rows 554-683
  grade row 2: rows 686-815
  ...
  total: rows 1347-1477

$ python -m card_grade_marker table.jpg --row 1
kept grade row 1 of 6 (rows 554-683) -> table_marked.png
```

- 指定した行以外のグレード行を、**表の枠と列の色は残したまま**消します
- **ヘッダー行と 合計 行は残します**（母数が分かるように）
- 残した行には枠線（`--mark ring`、既定）または矢印（`--mark arrow`）を付けます
  - 矢印は枚数の右隣から伸ばすので、数字は隠れません（桁の間の隙間を数字の
    終わりと誤認しないよう、近い字はひと続きとして扱っています）

表の検出は、**縦に長い線＝表の枠と列区切り**、**横に長い線＝行区切り**、その間が
行、という規則だけで行っています。タブ下の画面いっぱいの区切り線は、表の外まで
伸びていることで区別して除外します。

## 検出のしくみ（チップレイアウト）

OCR は使わず、形で見つけます。

1. 画面全体から、**同じ幅・同じ中心を持つ水平な線の対**（＝角丸長方形の上辺と
   下辺）を探し、チップ行の候補とする。
2. 候補の帯の中で、背景より明るい画素を x 方向に射影し、連続した列をチップ候補
   とする。**上辺と下辺の両方が閉じている**ものだけをチップとして残す（見出し
   の文字列はこの条件で落ちる）。
3. 幅とピッチが揃っている候補ほど高く採点し、最も「チップ行らしい」帯を採用する。
4. 各チップの**枠線**が白ければ、アプリ側で選択中のチップと判定する（チップ内
   の数字も白いため、枠だけを見る）。

そのため、白枠の選択チップが写っていないスクリーンショットでは自動判別ができ
ません。その場合は `--target` で位置を指定してください。行の検出自体に失敗する
ときは `--band` で行範囲を渡せます。

チップが1つしか写っていない行（横スクロールで1つだけ見えている、あるいはこの
ツールで加工済みの画像）も検出できますが、複数チップが並ぶ行があればそちらを
優先します。チップに何かが重なっていて1つの塊として読まれてしまう場合は、
`--chip X0:X1` で残す列範囲を直接指定してください。
