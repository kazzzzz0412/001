# 動画の書き出し（Windows）

元動画は大きくてやり取りできないので、**書き出しは動画のあるPCで行う。**

## 1. 準備（初回だけ）

```
pip install imageio-ffmpeg pillow
```

`ffmpeg` を別途入れる必要はない。`imageio-ffmpeg` が同梱のものを使う。

**日本語フォントは自動で探す。** メイリオ → 游ゴシック → MSゴシック の順に見つかったものを使う。
うまく見つからない場合だけ、編集指示JSONに明示する。

```json
"font": "C:/Windows/Fonts/meiryob.ttc",
```

## 2. 元動画のパスを書く

`車関係_編集指示_01.json` の `"source"` を書き換える。

```json
"source": "C:/Users/あなた/Downloads/carwow_lfa_vs_viper.mp4",
```

> ⚠️ **JSONではバックスラッシュを `/` に書き換えること。**
> `C:\Users\...` と書くと JSON のエスケープとして解釈されて壊れる。
> `C:/Users/...` か `C:\\Users\\...` のどちらかにする。**前者を推奨。**

## 3. 実行

```
python 車関係_動画生成.py 車関係_編集指示_01.json
```

`out/車関係_01_バイパーvsLFA.mp4` が出る（720×1280 / 30fps / H.264+AAC / 70秒）。

> Windows では `python3` ではなく **`python`**。

## 4. 出来上がったら確認するところ

タイムコードは Gemini の出力に基づいており**未検証**なので、まずここを見る。

| 時刻 | 映っているべきもの |
|---|---|
| 0秒 | Viperが白煙を上げて急発進 |
| 11.5秒 | 字幕 `3 2 1` とスタート |
| 42秒 | 終盤の逆転 |
| **54秒** | **ハーフマイル通過（LFAが先）** |
| **59秒** | **「実は ダッジの勝ちだった」** |
| **62秒** | **パネルのVIPER側が光る** |
| 63秒 | タイム表示 12.1 / 12.2 |

ズレていたら `車関係_編集指示_01.json` の `segments` と `subtitles` の数字を直して再実行する。
**JSONを直すだけでよく、スクリプトは触らなくてよい。**

---

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| `元動画が見つかりません` | `source` のパスを確認。バックスラッシュを `/` にする |
| `日本語フォントが見つかりません` | JSONに `"font"` を追加して明示する |
| `python` が見つからない | Python 3 をインストール（python.org または Microsoft Store） |
| 字幕が豆腐（□□□）になる | フォントが日本語非対応。`"font"` でメイリオを明示する |
| パス関連で ffmpeg が落ちる | リポジトリを `C:/work/001` のような**日本語を含まないパス**に置いて再実行 |

## Claude Code をPCで使う場合

このリポジトリをクローンしてセッションを開けば、`CLAUDE.md` から制作ルールが自動で読まれるので
経緯の説明は不要。

```
git clone -b claude/car-short-video-production-fn4xvv https://github.com/kazzzzz0412/001.git
```

元動画のダウンロード、タイムコードのフレーム実測、JSONの修正、書き出しまで任せられる。
