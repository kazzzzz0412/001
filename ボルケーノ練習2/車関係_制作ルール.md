# 車関係ショート動画 制作ルール（ボルケーノ練習2）

このファイルがこのプロジェクトの **単一の正** です。
Claude はセッションをまたぐとメモリを保持できないため、運用ルールはすべてここに書く。
セッション開始時にまずこのファイルを読むこと。

- テーマ: 車好き向け YouTube Shorts（非属人 / 顔出しなし）
- 手法: ボルケーノ式「ネオ・切り抜き」（出典: Drive「切り抜き動画で2ヶ月で1億回再生を突破した戦略の全て」）
- ファイル名接頭辞: `車関係_`
- 別テーマ（ボルケーノ練習）とは絶対に素材・台本を混在させない

---

## 1. 大原則（ここを外すと何をやっても無駄）

1. **強い素材を選ぶ** — 元動画が伸びていない素材は、編集では救えない
2. **伸びている動画の構造を徹底的に模倣する** — 初心者のうちはアレンジしない（守破離の「守」）

プロセスはこの3つだけ:
① 切り抜き元を見つける → ② 参考フォーマットを決める → ③ 構造を徹底模倣する

## 2. 素材選びの基準（車ジャンル）

- 元動画の再生回数が高いものが正義（YouTube横動画なら安定10万回以上、理想は50万回以上）
- 素材はYouTube長尺に限らない: **TikTok / Instagramリール / 配信アーカイブ / 海外の車系アカウント**
- 海外素材 × 日本語字幕は、元が伸びていなくても化ける余地がある（車系は特に相性が良い）
- 自分が普段見ているジャンルを選ぶ（反応するポイントが体感で分かる＝強い）
- 「切り抜きがまだ少ない × 元は伸びている」チャンネルが最大の狙い目

## 3. 許可取り（最重要 / ここが参入障壁）

**無許可運用はしない。** 申し立て一発でBANされる。ここを面倒がる人が脱落するので、逆にここが勝ち筋。

伝えるべき3点:
1. 相手のメリット（認知拡大 / 本編への流入 / 新規ファン獲得）を**具体的な数字**で
2. **イメージ動画（試作品）を必ず添付** — 文章100行より速い
3. 最低限の保証（編集・投稿・分析はこちら負担 / NG表現に従う / 問題あれば即削除）

- 収益分配の話は**こちらから切り出さない**。聞かれてから交渉する
- 条件は必ず文面で残す
- 返信が来なければ次、断られたら次。数を打つ

## 4. フォーマット選定の3条件

すべて満たすこと。ひとつでも欠けると長期的に厳しい。

1. **伸びること**
2. **収益化審査に耐えること**
3. **量産できること**（1本の制作time ≦ 1時間。超えるフォーマットは副業として不成立）

審査で危険な動画: AI大量生成 / 画像を並べただけ / ほぼ転載 / テロップだけ追加 / 誰でも作れるテンプレ

## 5. 編集の必須要件（収益化審査を通すため）

1. **シーンごとにクロップを動かす**（必須。縦に切り出すだけはNG。話者交代・リアクション・強調点で画角を変える）
2. **字幕は必ず付ける**（必須）
3. **元動画のタイムラインをそのまま使わない**（間をカット / 順番を入れ替え / オチに向けて再構成）
4. **効果音・演出を足す**（笑いどころ、強調、ズーム）
5. **元音声に依存しすぎない**（ナレーション・補足で独自性を足す。ベター項目）
6. **複数素材を組み合わせる**（独自性が大きく上がる。積極的に行う）

## 6. 構成の型

- **尺は20〜30秒が基本**。長くするのではなく、不要な部分を削る
- **冒頭1〜2秒で「見る理由」を作る**（結末の一部を先に見せる / 何が普通と違うのか提示）
- 時系列どおりに始める必要はない
- 「この1秒は本当に必要か？」を常に問う
- 削りすぎて文脈・感情・オチが伝わらなくなるのはNG

切り抜く前に必ず決めること → **「この動画では視聴者に何を見てもらうのか」**
（同じ素材でも、誰を主役にするかでまったく別の動画になる。ここが唯一のオリジナリティ）

## 7. 投稿・分析

- 最低1日1本、理想は1日2本。量が正義
- 1本の結果に一喜一憂しない（9本10万回 + 1本200万回 で平均30万回、という世界）
- 伸びない原因は基本2つだけ: ①ジャンルが悪い ②フォーマットを模倣しきれていない
- 20本投稿して1本も5万回に届かないならジャンルを変える
- 当たりが出たら要因を分解して横展開する
- 収益化: 登録1,000人 + 90日で1,000万回（エンゲージビュー基準なので実質2,000万回）。300万回時点で一次審査を出す

## 8. このプロジェクト固有の取り決め

### ファイル命名
```
車関係_参考動画分析_<通し番号>.md    参考動画の構造分解
車関係_台本_<通し番号>.md            1本分の構成台本＋字幕
車関係_許可取り_<相手名>.md          許可取りの文面と経緯
```

### 作業フロー
1. 参考動画の構造分解（`車関係_参考動画分析シート.md` を複製して使う）
2. フォーマット定義に落とす
3. 車素材を当てはめて台本＋字幕を作る
4. 編集指示（クロップ・効果音・テンポ）まで書き切る

### 字幕スタイル
> **未確定** — ユーザーの指定待ち。決まったらここに追記する。
> 決めるべき項目: フォント / サイズ / 色・縁取り / 表示位置 / 1画面あたりの文字数 /
> 強調語の扱い / 改行位置のルール / エフェクトの有無

### 環境上の制約（重要）
- このクラウドセッションからは **YouTube にアクセスできない**（egress ポリシーで遮断）
- 動画・音声を直接視聴することもできない
- したがって **「動画を見る」のはユーザー、「型に落とす」のが Claude** という分担で進める
- 参考動画は URL ではなく、字幕書き起こし・秒単位のメモ・スクショで渡してもらう
