## 1. このフォーマットの核心

**縦型フレームは「静止した情報パネル」で、動くのは中央の 16:9 クリップだけ。**
33.71秒間、ヘッダー・見出し・スペック表・価格ボックスは **1ピクセルも変化しない**。

これが意味すること:
- テンプレートを一度作れば、以降は **クリップと数値を差し替えるだけ** → 量産性が極めて高い
- 横長素材を縦に切り出す手間がゼロ（レターボックスの余白を情報で埋めている）
- 「何と何が戦うのか」が常時画面に出ているので、**途中から見た人にも文脈が伝わる**

| 用途 | 値 |

ゴールドを使う箇所は **4つだけ**: 見出しの数値部分／HPの大数字／価格／車名の一部下線。
それ以外は白とグレー。**色数を絞っているのが効いている。**

## 4. タイポグラフィ

- 書体: 日本語は太めの角ゴシック（Noto Sans JP Bold / ヒラギノ角ゴ W6 相当）。欧文は同系のサンセリフ
- **見出し**: 2行、約34px相当。数値だけゴールド、助詞以降は白
  - 実際の文言: `600馬力のGRヤリスが` / `812に挑む。`
  - → **「600馬力」「812」がゴールド**、「のGRヤリスが」「に挑む。」が白
- **車名**: 白ボールド、約17px。`TOYOTA GR YARIS` / `FERRARI 812 SUPERFAST`
  - **モデル名の一部（GR / 812）にだけゴールドの下線**が入る（細部だが効いている）
- **HP大数字**: ゴールド、約40px。単位 `HP` は白の小サイズで添える
- **スペックラベル**: グレー約11px（エンジン／最大トルク／車重／駆動方式）
- **スペック値**: 白約14px
- **価格**: ゴールド約22px。注釈「※カスタム費用込み」はグレー約10px

各スペック行の左端に **線画アイコン**（エンジン＝ブロック、トルク＝円弧、車重＝重り、駆動方式＝シャフト）。

## 6. カット割り（シーン検出の実測値）

カット点: **5.20 / 7.03 / 9.37 / 12.50 / 15.53 / 17.47 / 19.33 / 21.47 / 24.20 / 25.40 / 29.20 / 31.30 秒**

- 総ショット数: **13**
- 平均ショット長: **約2.6秒**
- **冒頭ショットだけ 5.20秒と長い** — スタートライン＋「3 2 1」カウントダウン＋発進までを切らずに見せる
- 以降は 1.2〜3.1秒で刻む。最短は 25.40→29.20 の手前、1.2秒（24.20–25.40）

**構成の流れ:**
1. `0.0–5.2` スタートライン（2台並び）＋「3 2 1」カウントダウン＋発進 ← **引き**
2. `5.2–15.5` 運転席（ドライバーの表情・リアクション）と併走の外撮りを交互に
3. `15.5–25.4` 追走・タコメーター・車外の流し撮りでスピード感
4. `25.4–31.3` 決着に向けた追い上げ（字幕「迫ってるぞ 頼む」）
5. `31.3–33.7` 引きの風景ショットで締め

## 7. 字幕（クリップ内）

- **クリップ窓の内側下部**にだけ置く。縦型フレーム側には字幕を出さない
- 白・細めの縁取り（または薄いドロップシャドウ）・**センター揃え**
- サイズは見出しよりかなり小さい（約18px相当）
- 短い。確認できた例: `3 2 1`（カウントダウン）、`近いぞ`、`どこだ`、`迫ってるぞ 頼む`
- 出っぱなしにせず、喋っている瞬間だけ 1〜2秒表示

> 注: 音声を聴取できないため、全字幕の文言と対応タイムコードは未確定。
> 上記は画面から読み取れたもののみ。

## 8. 再現手順

1. **720×1280 のテンプレートを作る**（上の座標表どおり）。中央 638×361 は空けておく
2. 16:9 の素材クリップを **クロップせずそのまま** 638×361 に配置（角丸8px）
3. 2台のスペックを差し替える
4. 見出しを書く。**数値だけゴールド**にする
5. 素材を 13ショット前後に刻む。**冒頭だけ5秒前後の長回し**、以降2〜3秒
6. 喋っている箇所にだけ短い字幕を入れる
7. 尺は 30〜35秒に収める

## 9. 注意点

- **素材の出どころ**: 運転手・ロケ地・撮影スタイルから、英国の自動車系チャンネル（carwow 系）のドラッグレース動画と見られる。なお本プロジェクトは非公開の練習用のため、権利処理は対象外（`車関係_制作ルール.md` 3章）
- **ボルケーノ教材との相違**: 教材は「シーンごとにクロップを動かせ」を必須としているが、この動画は **クロップを一切動かさず**、代わりに画面の6割以上を独自制作の情報パネルで埋めることで独自性を出している。別解ではあるが、教材の想定とは異なるアプローチである点は認識しておくこと
- 情報パネルの数値は自前で調べて載せる必要がある。**ここが唯一の手間**であり、同時に他チャンネルとの差別化点でもある
