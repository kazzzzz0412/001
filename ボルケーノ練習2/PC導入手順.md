# PC（Windows）で動画を書き出せるようにする手順

初心者向け。**ターミナル（黒い画面）は使いません。**
全部でだいたい20〜30分。インストールの待ち時間がほとんどです。

---

## 全体像

必要なものは3つだけ。

| # | 入れるもの | なぜ必要か |
|---|---|---|
| 1 | **Claude Desktop** | PC上でClaudeに作業させるため |
| 2 | **Git for Windows** | このプロジェクトをPCに持ってくるため |
| 3 | **Python** | 動画を書き出すスクリプトを動かすため |

3つ入れたら、あとはClaudeに話しかけるだけです。

---

## ステップ1: Claude Desktop を入れる

1. [Windows版をダウンロード](https://claude.ai/api/desktop/win32/x64/setup/latest/redirect)
2. ダウンロードした `.exe` をダブルクリックしてインストール
3. 起動して、いつも使っているアカウントでサインイン
4. 画面上部に **Chat / Cowork / Code** の3つのタブがあります。**Code** をクリック

> 💡 スマホやブラウザで使っていたのと同じアカウントでOKです。
> クラウド側の会話履歴とは別物ですが、このプロジェクトの情報はGitHubに全部入っているので問題ありません。

---

## ステップ2: Git for Windows を入れる

1. [git-scm.com からダウンロード](https://git-scm.com/downloads/win)
2. `.exe` を実行
3. **設定はすべてデフォルトのまま「Next」を押し続けて大丈夫です**（項目が多いですが変更不要）

---

## ステップ3: Python を入れる

1. [python.org からダウンロード](https://www.python.org/downloads/)（黄色い「Download Python」ボタン）
2. `.exe` を実行
3. ⚠️ **最初の画面で「Add python.exe to PATH」に必ずチェックを入れてから** 「Install Now」

> これにチェックを入れ忘れると後で動きません。ここだけ注意してください。

---

## ステップ4: 作業フォルダを作る

エクスプローラーで `C:\` の直下に **`work`** という名前のフォルダを作ります。

```
C:\work
```

> 日本語やスペースを含まない場所にするのがコツです。トラブルが減ります。

---

## ステップ5: Claude に丸投げする

1. Claude Desktop の **Code** タブを開く
2. 新しいセッションを作り、プロジェクトフォルダに **`C:\work`** を指定する
3. 下のメッセージを**そのままコピーして貼り付け**、送信する

```
GitHubから私のプロジェクトを持ってきてください。

  リポジトリ: https://github.com/kazzzzz0412/001.git
  ブランチ:   claude/car-short-video-production-fn4xvv

クローンしたら ボルケーノ練習2/ の中の CLAUDE.md と 車関係_制作ルール.md を
読んで、今何をしようとしているか把握してください。
```

Claudeが読み込みを終えたら、次はこれを送ります。

```
carwowの動画をダウンロードして、1本目のショート動画を書き出してください。

  素材: https://youtu.be/4WMGC5MIfPc
  台本: ボルケーノ練習2/車関係_台本_01_バイパーvsLFA.md
  手順: ボルケーノ練習2/render/README.md

注意: 編集指示のタイムコードはGeminiの出力に基づいていて未検証です。
書き出す前に、動画からフレームを抜き出して実際の時刻を確認してください。
ズレていたら 車関係_編集指示_01.json を直してから書き出してください。
```

これで `C:\work\001\ボルケーノ練習2\render\out\` に完成品が出ます。

---

## うまくいかないときは

**Claudeにそのまま伝えてください。** エラーメッセージをコピーして貼るだけで対処してくれます。
自分で原因を調べる必要はありません。

よくあるもの:

| 症状 | 伝え方 |
|---|---|
| `python は認識されていません` | 「PythonのPATHが通っていないようです」と伝える（ステップ3のチェック忘れ） |
| `git は認識されていません` | 「Gitが入っていないようです」と伝える |
| 字幕が □□□ になる | 「字幕が豆腐になっています」と伝える |
