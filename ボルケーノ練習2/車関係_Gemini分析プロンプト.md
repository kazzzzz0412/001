# 車関係_Gemini分析プロンプト

用途別に2種類ある。**使い分けを間違えないこと。**

| | 使う場面 | プロンプト |
|---|---|---|
| **A** | URL しか手元にない | 下の「A. 全体分析用」 |
| **B** | 動画ファイルがある | 下の「B. 音声特化用」← Claude が映像を実測済みなので音声だけ埋める |

**ファイルが手元にあるなら B を使う。** 映像側（座標・色・カット点・レイアウト）は Claude が
ffmpeg で実測できるので、Gemini に同じことをさせるのは無駄。Gemini にしか取れないのは音声。

# B. 音声特化用（動画ファイルがある場合）

動画ファイルを Gemini にアップロードして、以下を貼る。
映像の構造は Claude が実測済みなので、**Gemini には音声だけを担当させる**。

返ってきた出力は該当する `車関係_参考動画分析_<番号>_*.md` に追記する。

## プロンプト本文（ここから下をコピー）

添付した動画の**音声**を分析してください。映像の構図・レイアウト・色については既に分析済みなので、
**触れなくて結構です。音声に関することだけ**を書いてください。

### 1. 発話の完全書き起こし

動画内で人が喋っている箇所を、**すべて**タイムコード付きで書き出してください。

| 開始 | 終了 | 話者 | 原語（英語等）の発話 | 日本語訳 |
|---|---|---|---|---|
| 0:00 | 0:00 | | | |

- 聞き取れない箇所は「（不明瞭）」と明記する
- 相槌・笑い声・息をのむ音なども、意味がある箇所は拾う
- 話者が複数いる場合は区別する

### 2. 画面に表示されている字幕との対応

画面下部に日本語字幕が出る箇所があります。**字幕の文言をそのまま**、表示開始・終了のタイムコード付きで
書き出してください。

| 開始 | 終了 | 字幕の文言（原文ママ） |
|---|---|---|

そのうえで、**字幕が発話の忠実な訳なのか、意訳・要約なのか**を判定してください。
発話していないのに字幕だけ出ている箇所があれば、それも指摘してください。

### 3. BGM

- BGM は入っているか
- 入っているならジャンル・テンポ（BPMの体感で可）・盛り上がりの位置
- 曲が切り替わる／音量が変わるタイミングがあれば、そのタイムコード
- 元動画の環境音（エンジン音など）とのバランス（どちらが主か）

### 4. 効果音

効果音が鳴っている箇所を**すべて**タイムコード付きで列挙してください。

| 時間 | 音の種類（ウーッシュ／ドン／キラーン等） | 何に合わせて鳴っているか |
|---|---|---|

### 5. エンジン音の扱い

- 元素材のエンジン音・排気音はそのまま使われているか、強調されているか
- 特に音を聴かせている箇所（タイムコード）

### 6. 音と映像の同期

カットの切り替わりが、音（ビート・効果音・発話の切れ目）と揃っているかどうかを判定してください。
揃っている場合、何に合わせて切っているかを書いてください。

### 注意
- **発話と字幕は要約せず、原文のまま**書き写すこと
- タイムコードは秒単位まで出すこと
- 推測が混じる場合は「（推測）」と明記すること
