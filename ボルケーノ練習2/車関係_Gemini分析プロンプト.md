# 車関係_Gemini分析プロンプト

用途別に2種類ある。**使い分けを間違えないこと。**

| | 使う場面 | プロンプト |
|---|---|---|
| **A** | URL しか手元にない | 下の「A. 全体分析用」 |
| **B** | 動画ファイルがある | 下の「B. 音声特化用」← Claude が映像を実測済みなので音声だけ埋める |

**ファイルが手元にあるなら B を使う。** 映像側（座標・色・カット点・レイアウト）は Claude が
ffmpeg で実測できるので、Gemini に同じことをさせるのは無駄。Gemini にしか取れないのは音声。

# B. 台本抽出・再構成用（動画ファイルがある場合）

動画ファイルを Gemini にアップロードして、以下を貼る。

**Gemini の本体価値はここにある。** 音声が取れる → 台本が取れる → 台本を再構成して自分の動画の
台本を作れる。さらに、元動画がバズっている場合はその要因を言語化できる。
映像の座標・色・カット点は Claude が ffmpeg で実測できるので、Gemini には台本と音を担当させる。

返ってきた出力は該当する `車関係_参考動画分析_<番号>_*.md` に追記する。

## プロンプト本文（ここから下をコピー）

添付した動画を分析してください。画面のレイアウト・座標・配色については既に別途分析済みなので
触れなくて結構です。**音声と台本、そしてなぜこの動画が見られるのか**に集中してください。

### 1. 発話の完全書き起こし

| 開始 | 終了 | 話者 | 原語の発話（原文ママ） | 日本語訳 |
|---|---|---|---|---|

- 聞き取れない箇所は「（不明瞭）」と明記
- 相槌・笑い・息をのむ音など、感情が出ている箇所も拾う
- 要約しないこと

### 2. 画面字幕との対応

画面下部に日本語字幕が出ます。**文言をそのまま**、表示タイムコード付きで。

| 開始 | 終了 | 字幕の文言（原文ママ） | 対応する発話 |
|---|---|---|---|

そのうえで判定してください:
- 字幕は忠実な訳か、意訳・要約か
- **全部の発話に字幕を付けているか、それとも一部だけか**（ここは重要。どの発話を選んで字幕にしたかに編集意図が出る）
- 発話がないのに字幕だけ出ている箇所があるか

### 3. 台本の構造化

書き起こしを、**動画の設計図として**再構成してください。

| ブロック | 時間 | 役割 | 内容 |
|---|---|---|---|

役割の例: フック／状況説明／期待の醸成／緊張の最高点／オチ／余韻

そのうえで:
- **視聴者が離脱しそうな箇所**はどこか、そこで何をして引き留めているか
- 最後まで見てしまう理由を一文で

### 4. バズ要因の分析

この動画が伸びている要因を、**再現可能な粒度で**言語化してください。
「編集が上手い」のような抽象論ではなく、他の素材でも真似できる形で書いてください。

- 冒頭2秒で何を提示しているか。それがなぜ効くのか
- 感情が動く瞬間はどこか（秒指定）。何の感情か
- 情報を出し惜しみしている箇所はあるか
- コメントを誘発しそうな要素はあるか
- **この動画から要素をひとつ抜いたら成立しなくなる、その要素は何か**

### 5. 新しい台本の生成

上の分析を踏まえて、**同じ構造で別の車の組み合わせに当てはめた台本**を3案作ってください。
素材は「海外の自動車系チャンネルにありそうなドラッグレース映像」を想定して構いません。

| 秒単位の構成 | |

| オチ | |

見出しは元動画の「600馬力のGRヤリスが／812に挑む。」と**同じ語感・同じ文字数感**で作ってください。

### 6. 音の設計

- BGM の有無・ジャンル・テンポ・盛り上がりの位置
- 効果音の一覧（時間／種類／何に合わせているか）
- エンジン音は強調されているか。聴かせている箇所はどこか
- カットの切り替えは音に同期しているか

### 注意
- **発話と字幕は要約せず原文のまま**
- タイムコードは秒単位まで
- 推測には「（推測）」と明記
- 4と5が本題です。1〜3はそのための材料なので、省略せず埋めてください
