## 4. 視聴維持率の設計

| 秒 | 危険度 | 対策 |
|---|---|---|
| 0–3 | 最重要 | **白煙と爆音**で殴る。静止画的な導入は絶対にしない |
| 3–11 | 高 | エンジン音2連発。**音だけで持たせる区間**。字幕は出さず音に集中させる |
| 11–15 | 中 | カウントダウンで「始まる」と分からせる。ここで離脱する人は元々見ない層 |
| 15–42 | **最も危険** | レース中盤。元動画のカット割り（3〜4秒ごと）をそのまま使い、字幕を3枚入れて間を埋める |
| 42–54 | 低 | 逆転が起きるので自然に持つ |
| 54–59 | **中** | 「決着したのに続く」ので離脱しやすい。**Nickが笑い、Matが困惑する画のちぐはぐさ**を残して「何かある」と感じさせる |
| 59–70 | 低 | どんでん返し。ここまで来た人はまず離脱しない |

**最大の勝負どころは 54–59 秒。** ここで「もう終わった」と思われたら負ける。
10:34 のゴール通過の直後に間を置かず、**すぐ Nick の歓声を被せる**こと。
LFAが先に通過したのに Viper のドライバーが喜んでいる、という**違和感が次の8秒を見させる**。

## 7. 勝者ハイライト（採用済み）

70秒は参考動画（33.7秒）の倍の尺があり、情報パネルが70秒動かないのは維持率のリスクになる。
対策として、**62秒の決着の瞬間にパネルの VIPER 側だけを強調する**カットを用意した。

**仕様:**
- 勝者（VIPER）側: 薄いゴールドの地（7%）＋ゴールドの細枠、車名がゴールドに変わる
- 敗者（LFA）側: 不透明度 38% に沈む
- **新しい要素は一切足していない。** 元フォーマットの静的な性格を壊さない

**書き出し済みファイル:**

| ファイル | 使う区間 |
|---|---|
| `out/overlay_alpha.png` | **0.0–62.0秒** |
| `out/overlay_alpha_winner.png` | **62.0–70.0秒** |

編集ソフトでは、62秒地点でこの2枚を差し替える。クロスフェード 0.2秒程度を推奨。
`車関係_データ.json` の `"winner": "left"` で勝者側を指定している（left=VIPER / right=LFA）。

## 9. 書き出し（自動）

編集ソフトで組む必要はない。**元動画さえあればコマンド1本で完成する。**

```
# 1. 元動画をダウンロードして、パスを編集指示に書く
#    render/車関係_編集指示_01.json の "source" を書き換える

# 2. 実行
pip install imageio-ffmpeg pillow
python3 ボルケーノ練習2/render/車関係_動画生成.py \
        ボルケーノ練習2/render/車関係_編集指示_01.json
```

`render/out/車関係_01_バイパーvsLFA.mp4` が出る（720×1280 / 30fps / H.264+AAC / 70秒）。

スクリプトがやること:
1. 6区間を切り出す
2. 連結する
3. 720×1280 の背景の中央 (41, 284, 638×361) に配置する。**角丸はオーバーレイ側が作る**
4. オーバーレイを重ね、**62秒で勝者ハイライト版に差し替える**
5. 字幕11枚を焼き込む（IPAゴシック・白・黒縁）
6. H.264 / AAC で書き出す

**検証済み**: 代用素材でパイプラインを通し、解像度・尺・音声・字幕位置（クリップ窓内・中央）・
62秒での差し替え（LFA列が沈み、VIPER列が明転）をすべて実測で確認した。

### 手で編集する場合

`template/out/overlay_alpha.png`（0–62秒）と `overlay_alpha_winner.png`（62–70秒）を
最上位レイヤーに置く。
