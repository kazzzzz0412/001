# card_title_overlay — カード写真にタイトル文字を焼き込む

カードの写真とタイトルを渡すと、**白抜き＋赤フチの太字ゴシック**でタイトルを
乗せます。文字は**カードにかからない**位置（カードの上下の空き）にだけ配置します
（鑑定ラベルの上は横切ります）。

## 使い方

```
pip install Pillow numpy
python -m card_title_overlay photo.jpg "希少 カイリキー 進化系 eカード 3連番 セット"
```

出力は既定で `photo_title.jpg`。`-o` で変更できます。

タイトルは空白区切りで、次のように3か所へ自動で振り分けます。

| 位置 | 内容 | 上の例では |
| --- | --- | --- |
| 上・小（左寄せ） | 先頭の語 | `希少` |
| 上・大（中央） | 続く2語をつなげたもの＝商品の主役 | `カイリキー進化系` |
| 下（中央） | 残り全部 | `eカード 3連番 セット` |

語数が少ないときは自動で縮退します（1語＝大のみ、2語＝大＋下、3語＝小＋大＋下）。
振り分けを自分で決めたいときは `--top` / `--main` / `--bottom` を使います。

```
python -m card_title_overlay photo.jpg --top 超希少 --main カイリキー進化系 --bottom "eカード 3連番 セット"
```

`--show` で、実際に描かずに「絵柄の行範囲・使うフォント・各行の文字列」だけを
確認できます。

### 主なオプション

| オプション | 説明 |
| --- | --- |
| `--top` / `--main` / `--bottom` | 各行の文字列を直接指定 |
| `-o, --output` | 出力先（既定: `<入力名>_title.jpg`） |
| `--font` | 使うフォントのパス |
| `--fill` / `--outline` | 文字色・フチ色（既定: 白／赤 `#E41E26`） |
| `--weight` | 太らせ量。フォントサイズに対する比（既定: フォント任せ） |
| `--tracking` | 字間。**字面どうしの間隔**をフォントサイズ比で指定（既定: 0.05） |
| `--bearing` | フォント本来の左右余白をどれだけ残すか。0〜1（既定: 0.45） |
| `--word-gap` | タイトルに空白があった位置の間隔。同じく比（既定: 0.34） |
| `--protect` | 文字を避ける対象。`card`（既定・カード全体）/ `art`（イラストのみ） |
| `--band Y0:Y1` | 避ける行範囲を直接指定（自動検出を使わない） |
| `--quality` | JPEG の品質（既定: 95） |
| `--show` | レイアウトだけ表示して終了 |

## カードを避けるしくみ

既定（`--protect card`）では、**カード全体**（ラベルを除く）を避けます。

1. 暗い背景に対して**明るい塊＝スラブ**の行範囲を求める。
2. その上部で**いちばん暗い谷（ラベルとカードの間にできるスラブ枠の影）**を探し、
   そこから下をカードとみなす。谷が無い写真では塊の上端をそのまま使います。
3. カードの上下の空きに、上段（小＋大）と下段を配置する。空きが足りなければ
   収まるまで縮小します。

`--protect art` にすると、**イラスト枠だけ**を避ける旧来の挙動になります（彩度の
高い画素の行占有率から、いちばん背の高い band を選ぶ方式）。淡い色のカードだと
イラスト以外が拾われず、カード名や技テキストの上に文字が乗るため、既定は
`card` にしています。

どちらの自動判定も外れる場合は `--band Y0:Y1` で行範囲を直接渡せます。

## 字間について

字間は「送り幅に一律加算」ではなく、**隣り合う文字の字面（インク）の間隔**を基準に
配置しています。カタカナは漢字より字面が小さく左右に余白を持っているため、送り幅
基準で詰めると「カ イ リ キ ー」のように間延びして見えるからです。

ただし字面基準だけにすると今度はカタカナが詰まりすぎるので、**フォント本来の左右
余白を `--bearing` の割合だけ戻して**います（0＝完全に字面基準、1＝送り幅基準、
既定 0.45）。余白の広いカタカナほど多く戻るので、漢字と並べたときの見た目が揃い
ます。タイトルに空白があった箇所だけは `--word-gap` のぶん広げ、語の切れ目が分かる
ようにしています。

## フォントについて

**太字ゴシック体（Noto Sans CJK JP Black）**で描きます。入っていない環境では
以下で導入できます（Debian / Ubuntu）。

```
./scripts/install-fonts.sh
```

未導入でも動きますが、その場合は IPAゴシック（標準ウェイト）を自前で太らせる
ため、本物の極太より軽い見た目になります。`--font` で任意のフォントを渡すことも
できます。探索順は Noto Sans CJK Black → Bold → IPAゴシック → 文泉驛正黑 です。

太らせ量（`--weight`）の既定は**フォント任せ**で、Bold / Black のフォントなら
太らせず、標準ウェイトのフォントのときだけ太らせます（画数の多い漢字の内側が
潰れるのを避けるため）。
